# GamedayTracker

A modern TypeScript Discord bot that delivers NFL game scores, live updates, and interactive Components V2 cards. Built with **discord.js v14**, **discord.js-v2**, and a clean ESNext + NodeNext architecture.

---

## Features

- 🏈 NFL scoreboard + game tracking  
- ⚡ Slash commands (auto-registered)  
- 🎨 Components V2 UI (cards, sections, displays)  
- 📁 Modular command + interaction handlers  
- 🔧 TypeScript + ESNext + NodeNext  
- 🔐 Environment variables via `.env`  
- 🚀 Clean, scalable folder structure  

---

## Tech Stack

- Node.js 18+  
- TypeScript  
- discord.js v14  
- discord.js-v2  
- dotenv
